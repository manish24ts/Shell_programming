# 📖 Overview

This repository contains practical implementations of fundamental **Operating System concepts** including CPU scheduling, deadlock avoidance, process synchronization, memory management, page replacement algorithms, inter-process communication (IPC), and Linux shell scripting.

The programs were developed as part of the **Operating System Laboratory** coursework to provide hands-on experience with core operating system concepts and Linux programming.

---

# 🎯 Objectives

- Understand Linux operating system fundamentals.
- Learn Bash scripting and Linux commands.
- Implement CPU scheduling algorithms.
- Study process synchronization techniques.
- Explore deadlock prevention and avoidance.
- Understand memory management strategies.
- Implement page replacement algorithms.
- Learn inter-process communication mechanisms.

# ⚙️ How to Run

Clone the repository

```bash
git clone https://github.com/manish24ts/OperatingSystemLab.git
```

Navigate into the repository

```bash
cd OperatingSystemLab
```

### Compile C Programs

```bash
gcc filename.c -o output
```

Run

```bash
./output
```

### Execute Shell Scripts

Give execution permission

```bash
chmod +x filename.sh
```

Run

```bash
./filename.sh
```
